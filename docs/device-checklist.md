# 真机检查清单

只列浏览器预览（`npm run dev`）和单元测试覆盖不到、必须在手机上看的项。不要求逐条过：较大的改动后挑相关的几项看。发现问题时记下机型、Android 版本、WebView 版本（设置 → 应用 → Android System WebView）和复现步骤。

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

数据库布局版本变化时（`ChatDatabase.VERSION`），覆盖安装会清空本地数据（账号、API Key、模型、会话），需要重新添加。0.0.x 期间不做迁移。

## 窗口与系统

- [ ] 冷启动不白屏；跟随系统切换深浅色时，状态栏和导航栏一起变，图标颜色正确。
- [ ] 系统字号调到最大 / 最小，正文跟着变，输入区和按钮不重叠。
- [ ] 软键盘弹出时输入框和发送键完整可见，收起后布局恢复。
- [ ] Back 先关浮层（对话框 → 面板 → 抽屉），再返回会话，首页退出。
- [ ] 抽屉跟手拖动；从屏幕最左边缘滑是系统返回；代码块、表格里横滑仍是滚动。
- [ ] 系统“移除动画”打开 / 关闭时，页面切换都没有黑帧；小鱼清晰无半像素。

## 对话

- [ ] 长回答（代码块、表格、公式）流式输出流畅，上滑阅读不被拉回底部；断网时公式照常显示。
- [ ] 回合进行中切后台、锁屏 1 分钟后回来，回合正常完成；前台服务通知结束后消失；完成 / 失败通知点开进入对应会话。
- [ ] 生成中强杀应用后重开：该会话标为失败，可以继续发送。
- [ ] 选图、竖拍照片方向正确；只支持文本的模型不允许附图。
- [ ] 编辑、重答、重试产生版本，“‹ 1/2 ›”切换和“回到这里 / 回到最新”正常。
- [ ] 并排回答：两三路同时输出时不卡；卡片能左右滑动、不带动页面；选一路后会话的模型和档位跟着变。

## 账号与端点（用真实 Key）

- [ ] API Key 用原生密码框填写，列出将发往的域名；改路线域名后需要确认才能发送。
- [ ] 每种用到的协议（Chat Completions / Responses / Messages）各发一轮，思考内容和用量正常；返回 30x 说明官方地址变了（不跟随重定向）。
- [ ] 带工具调用的模型连续两轮工具调用不报 400；联网“自动 / 开启”有来源。
- [ ] 断开代理后发送，提示检查网络或代理，不是 Key 无效。
