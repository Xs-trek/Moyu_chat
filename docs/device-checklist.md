# 真机检查清单

浏览器预览（`npm run dev`）能覆盖布局和交互，但下面这些只能在手机上确认。每次较大的改动后过一遍；发现问题时记下机型、Android 版本、WebView 版本（设置 → 应用 → Android System WebView）和复现步骤。

安装包：`npm run verify` 之后在 `android/app/build/outputs/apk/debug/app-debug.apk`。

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## 0. 首次安装须知

- beta 线使用新的库文件 `moyu-beta.db`（当前 schema 2；v1 原地升级，不清数据）。旧的 beta 数据（`moyu-chat.db`）在首次启动时删除，需要重新添加 Provider、填 API Key、建 Model Profile。
- 启动时会清掉没有对应 Provider 的 API Key 和没有引用的图片。

## 1. 外观与窗口

- [ ] 冷启动不白屏：浅色、深色系统下各冷启动一次，启动瞬间窗口底色与页面底色一致。
- [ ] 主题“跟随系统”：在系统设置里切换深色模式，页面、状态栏、导航栏一起切换；状态栏图标在浅色底上为深色、深色底上为浅色（Android 8–10 与 11+ 各看一台更好）。
- [ ] 三种底色（灰绿 / 暖米 / 中性）切换后，状态栏和导航栏颜色同步。
- [ ] 系统字号：把系统字体调到最大和最小各一次，回到应用后正文跟着变（上限 160%、下限 85%），按钮、标签、底部输入区不重叠、不被截断。

## 2. 输入与导航

- [ ] 软键盘弹出时输入框和发送按钮完整可见，时间线不被顶到看不见最新消息；收起键盘后布局恢复。
- [ ] 输入多行文本时输入框增高，超过上限后内部滚动。
- [ ] Back：依次关闭对话框 → 底部面板 → 回合导航 → 抽屉；在 Provider / 设置 / 统计页按 Back 回到当前会话；首页按 Back 退出。
- [ ] 抽屉在竖屏为浮层；横屏或平板宽度 ≥ 960px 时固定在左侧。
- [ ] 抽屉手势：在页面上向右滑拉出抽屉、在抽屉或遮罩上向左滑收起，抽屉跟手；慢慢拖过一半松手停在打开，没过一半回弹；快速一甩按方向开合。从屏幕最左边缘滑是系统返回手势，不算抽屉手势。在代码块、表格、来源条上横滑仍然是横向滚动。
- [ ] 会话多选：在侧边栏和首页列表长按一条会话进入多选（不弹系统菜单、不选中文字），松手时不会打开这个会话；点其它会话切换勾选；生成中的会话是灰色的、点了提示不能删除。“全选 / 全不选”、确认后批量删除，删除的项淡出收起、其余补位。Back、✕、关闭侧边栏都能退出多选；长按时抽屉不会被拖动。
- [ ] 抽屉底部三个入口（Provider 与模型 / 统计 / 设置）紧凑排列，当天没有用量时也不会被拉开。
- [ ] 动效：切换页面有滑入（进入设置等更深页面从右侧、返回从左侧）；切换会话淡入；新消息上浮出现；展开 / 收起回复详情、底部面板、对话框、提示都有进出动画；设置里的开关和分段按钮点下立即变化且有过渡。系统开启“移除动画”后这些都不播放。
- [ ] 不闪：在设置页切换开关、在统计页切换周期、在本轮设置里改选项时，页面不重建、滚动位置不变；统计页切换周期时旧数字变淡，新数字到了原地替换。
- [ ] 页面栈：从侧边栏进入设置 / 统计 / Provider，新页面从右侧整页推入、旧页面左移变暗；Back 返回时反向；切换会话是交叉淡入。
- [ ] 分段控件（主题、底色、新会话默认、本轮设置、统计周期）点下时滑块平移到新位置。
- [ ] 展开回复详情、推理块、部署参数时高度平滑展开；回复详情在时间线底部展开后会自动滚到可见。
- [ ] 按压：按钮按下轻微缩小，主按钮和发送键有水波。
- [ ] 系统开启“移除动画”后：没有位移和缩放，只有短暂的淡入淡出；在会话、设置、统计、Provider 之间来回切换时没有任何黑帧或变暗闪烁。
- [ ] 正常动画下同样来回切换：没有黑帧；返回时下层页面从轻微变暗恢复到正常。

## 2a. 像素小鱼与彩蛋

- [ ] 小鱼在空会话页、输入框上沿、侧边栏标题、会话列表“生成中”、错误卡片里都清晰，没有模糊或半像素，深浅色下都看得清。
- [ ] 发送一条消息：输入框上的小鱼跳一下，之后随阶段换动作（思考吐泡泡、联网放大镜、输出打字、校验眯眼），完成时欢呼；点停止时冒感叹号。长回答（> 3000 字）时额头冒汗。
- [ ] 输入框上的小鱼不挡输入、发送键和“回到底部”；软键盘弹出时位置正确。
- [ ] 回合超过 10 秒：状态行出现“点小鱼摸会儿鱼”；点小鱼打开小游戏，拖动流畅，躲鱼钩、接泡泡计分；回答完成后提示并在 3 秒后收起；Back 能关闭；最高分重启后还在。
- [ ] 老板键：双击会话标题，整个界面变成文档样式（标题是文件名、提问前有“批注：”、看不到小鱼和用量），能正常发消息；再双击恢复；伪装时重启应用仍是伪装。
- [ ] 彩蛋：在空会话页的大鱼上慢慢划过冒爱心（不会拉出侧边栏）；侧边栏小鱼连点 5 下游过标题栏；点赞跳、点踩缩；1–5 点发消息打哈欠；空会话页偶尔自己动一下；打字时低头看；放着 60 秒不动戴墨镜刷手机，一碰就收。
- [ ] 关闭“动效与彩蛋”或系统“移除动画”后，小鱼完全静止，上述彩蛋都不出现（老板键仍可用）。
- [ ] 长时间流式输出时没有掉帧，耗电无明显变化。

## 2b. 统一风格（不再有原生控件）

- [ ] 设置页的上下文模式、联网、子 Agent 都是分段按钮，没有系统下拉框。
- [ ] Provider 页“新会话”弹出底部面板选择上下文模式和联网，点“开始”进入新会话。
- [ ] 添加 / 编辑 Provider 和模型都是全屏编辑页（从右侧推入，Back 关闭）。填错保存时，页面顶部展开错误说明且不关闭；保存成功后关闭并提示。
- [ ] 模型编辑页：输入 Model ID 后“Model Catalog 将解析为”卡片更新；切到“高级配置”时部署声明区展开；协议、鉴权方式等点开是底部选择面板。
- [ ] API Key：编辑页点“填写 / 更换”弹出系统密码输入框（唯一的原生表单），保存后编辑页里的状态变成“已配置”。新 Provider 首次保存且没有密钥时会自动弹出这个输入框。
- [ ] 原生错误（例如打不开链接）显示在页面顶部的提示条里，不再是系统 Toast。

## 2c. 账号与模型（provider-core）

- [ ] 首次启动新版本：旧的账号、模型和会话被清空（schema 1 布局重置），应用正常进入空状态。
- [ ] 添加账号 → 选 OpenCode Go：自动带出 Chat / Responses / Messages 三条路线，地址为 `opencode.ai/inference/go/…`；原生密码框列出将发往的域名。
- [ ] OpenCode Go 的实际请求能通：分别用一个 Chat 模型（如 glm-5.3-flash）、一个 Messages 模型（如 qwen3.8-flash）各发一轮。若返回 30x 错误，说明官方地址变了，把路线地址改成文档里的新地址（应用不再跟随重定向）。
- [ ] 模型编辑页“从目录选”：能力列表逐项显示“目录 · 未实测”；改一项后显示“手动”，可恢复推荐值。
- [ ] 改一条已有 Key 的路线的域名：账号页出现“确认域名”，确认前发送会提示需要确认，确认后正常。
- [ ] 新建账号保存后不关页面，再点一次保存、或填完 Key 再保存：不报错，路线数量不变，已加的模型还在。
- [ ] DeepSeek（如有 Key）：新建账号带出 Responses / Chat Completions / Anthropic 三条路线，新模型默认挂在 Responses 上；`deepseek-flash` 在 Responses 上能发一轮、思考内容可见，推理档位选“none”后不再思考。
- [ ] DeepSeek Responses：开启工具调用的会话连续两轮工具调用不报 400（推理条目按原样回传）。
- [ ] DeepSeek Chat Completions：思考模式下开启工具调用的会话连续两轮工具调用不报 400。
- [ ] 已有的 DeepSeek 账号：“添加路线”里出现“DeepSeek · Responses”，添加后可以从目录选 `deepseek-flash`。
- [ ] 断开代理后发送：提示“检查网络或代理”，不是 Key 无效。
- [ ] 停用一个模型：它从新会话和模型选择里消失，账号页仍可编辑。

## 3. 对话

- [ ] 流式输出流畅，长回答（含代码块、表格）滚动不跳动；手动上滑阅读时不会被强制拉到底部，“回到最新”按钮可用。
- [ ] 代码块有高亮（注释灰色斜体、关键字强调色），“复制”复制的是原始代码。
- [ ] 回合进行中切到后台、锁屏 1 分钟后回来，回合正常完成或停止；通知栏有前台服务提示，结束后消失。
- [ ] 中断：生成中点停止，回复标为“已中断”，可以继续发送。
- [ ] 图片：选图、预览、发送；只支持文本的模型不允许附图。
- [ ] 长会话（几十轮）打开和滚动不卡顿，侧边“回合导航”可跳转。
- [ ] 回退、编辑后重发、从某条分支，结果与预期一致。

## 4. 观察与对比

- [ ] 展开回复详情：用量、联网来源、校验结论正确；“调用链”加载出各阶段，跳过的阶段写明原因，标题行显示辅助调用占比。
- [ ] 极简 / 标准 / 智能各发一轮，调用链里启用和跳过的阶段与模式相符（极简只有生成；智能在设置里打开路由后才有路由，必要时有校验）。
- [ ] 路由默认关闭：升级安装后，设置里的“路由”开关是关的；打开后重启应用仍是开的。
- [ ] 智能模式首轮带图片发送（打开路由）：发送后输入框里不再出现那张图片；路由等待期间输入的字、改的标题在回答后仍在。
- [ ] 修正未采用：智能校验触发改写、但改写版没过复查时，回答仍是原文，详情里有“看没采用的修正版”。
- [ ] 账号检查：连接测试时连点“测试”只提示“正在检查”；慢端点超过 15 秒也不会先报“请求超时”。
- [ ] 协议报文：调用链底部点某次调用，请求页是格式化 JSON 和 URL，响应页是原始 SSE 行；报文里看不到 API Key 和请求头，图片只显示长度。设置里关闭“记录协议报文”后，新回合不再有报文。
- [ ] 重答：用户消息菜单 → 换个模型或模式重答，生成新分支并自动发送；两个回答都显示“2 答”，对比面板能看到两次回答并能跳转。
- [ ] 评价：回答菜单标“好答案 / 不好”，底部出现标记，统计页的评价数随之变化。
- [ ] 统计页：7 / 30 / 90 天切换正常，数字与实际使用大致相符。

## 5. 联网与工具（有对应能力的模型）

- [ ] 联网“自动”：时效性问题触发联网，调用链里联网规划写明查询，来源可点开。
- [ ] 联网“开启”：强制检索；“关闭”：不联网。
- [ ] 支持客户端工具的模型：子任务、web_search / web_fetch 工具轮次正常，调用链里能看到多轮生成和子任务用量。
- [ ] 按需联网：联网“自动”时问一个规则不会判为联网、但需要新信息的问题（例如“这个库最新版本是多少”换个说法），调用链“工具”阶段写“按需联网”。模型自己搜了的话，“生成”阶段写“自行联网”，并且有来源。设置里关掉“按需联网”后不再提供工具。
- [ ] 原文回查：在一个长会话（或上下文设得很小的模型）里问很早之前提到的具体数字或名字，调用链“工具”阶段写“可回查原文”，“生成”阶段有“回查 n 次”，回答用到了原话。

## 6. 稳定性

- [ ] 生成中强杀应用后重开：该会话标为失败，最后一轮的调用链状态为 `process_died`，可以继续发送。
- [ ] 断网时发送：错误提示清楚，恢复网络后可以重发。
- [ ] 失败后重试：断网发送失败后恢复网络，点时间线末尾的“重试”，失败那一轮被替换成新回答；输入框里打了一半的字还在。
- [ ] 后台通知（Android 13+ 首次发送时弹授权框）：发送后切到后台，回答完成 / 失败各出现一条通知，点开进入对应会话；生成中自己点停止不通知；设置里关掉后不再通知。
- [ ] 竖拍照片：导入后方向正确，全屏查看时单击放大、拖动查看、返回键关闭。
- [ ] 数学公式：让模型写含 $…$ 和 $$…$$ 的推导，公式正常排版；“$5 到 $10” 这类价格不变形；断网时公式照样显示（本地字体）。
- [ ] 全局自定义指令：设置里写一条（例如“回答末尾加一句总结”），新回合生效；清空后不再生效。
- [ ] 跨会话记忆（设置里打开）：在另一个会话里问之前长回答末尾提到的细节，能被找回。
- [ ] 升级到 schema 2（覆盖安装，不卸载）：账号、模型、会话和历史都还在；预算页的今日 / 本月花费和升级前一致。
- [ ] 失败后重试：新回答的回复详情 → 调用链末尾显示“第 2 次尝试，上一次：失败 · …”；统计页回合数里出现“已回退 1”，关掉“包含已回退的回合”后数字减少。
- [ ] 辅助模块开关：设置里关掉“校验与修正”，智能模式会话发一轮，调用链里校验显示“已在设置中关闭”；统计按“辅助开关”分组能看到两组。
- [ ] 新会话：点“新会话”后不发送，侧边栏不多出一条；再点一次也不会堆出空会话。输入框打几个字后切到别的会话，侧边栏出现“草稿：…”，点回去字还在。
- [ ] 自动命名：发第一条消息后标题立刻变成消息开头；回答完成后几秒内标题换成模型起的短标题（侧边栏和标题栏淡入）；调用链末尾有“命名”阶段。手动改名后不再被自动改；会话菜单“重新命名（自动）”可以重新生成。
