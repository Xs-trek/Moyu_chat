# 真机检查清单

浏览器预览（`npm run dev`）能覆盖布局和交互，但下面这些只能在手机上确认。每次较大的改动后过一遍；发现问题时记下机型、Android 版本、WebView 版本（设置 → 应用 → Android System WebView）和复现步骤。

安装包：`npm run verify` 之后在 `android/app/build/outputs/apk/debug/app-debug.apk`。

```bash
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

## 0. 首次安装须知

- beta 线使用新的库文件 `moyu-beta.db`（schema 1）。旧的 beta 数据（`moyu-chat.db`）在首次启动时删除，需要重新添加 Provider、填 API Key、建 Model Profile。
- 启动时会清掉没有对应 Provider 的 API Key 和没有引用的图片。

## 1. 外观与窗口

- [ ] 冷启动不白屏：浅色、深色系统下各冷启动一次，启动瞬间窗口底色与页面底色一致。
- [ ] 主题“跟随系统”：在下拉菜单切换系统深色模式，页面、状态栏、导航栏一起切换；状态栏图标在浅色底上为深色、深色底上为浅色（Android 8–10 与 11+ 各看一台更好）。
- [ ] 三种底色（灰绿 / 暖米 / 中性）切换后，状态栏和导航栏颜色同步。
- [ ] 系统字号：把系统字体调到最大和最小各一次，回到应用后正文跟着变（上限 160%、下限 85%），按钮、标签、底部输入区不重叠、不被截断。

## 2. 输入与导航

- [ ] 软键盘弹出时输入框和发送按钮完整可见，时间线不被顶到看不见最新消息；收起键盘后布局恢复。
- [ ] 输入多行文本时输入框增高，超过上限后内部滚动。
- [ ] Back：依次关闭对话框 → 底部面板 → 回合导航 → 抽屉；在 Provider / 设置 / 统计页按 Back 回到当前会话；首页按 Back 退出。
- [ ] 抽屉在竖屏为浮层；横屏或平板宽度 ≥ 960px 时固定在左侧。

## 3. 对话

- [ ] 流式输出流畅，长回答（含代码块、表格）滚动不跳动；手动上滑阅读时不会被强制拉到底部，“回到最新”按钮可用。
- [ ] 代码块有高亮（注释灰色斜体、关键字强调色），“复制”复制的是原始代码。
- [ ] 回合进行中切到后台、锁屏 1 分钟后回来，回合正常完成或停止；通知栏有前台服务提示，结束后消失。
- [ ] 中断：生成中点停止，回复标为“已中断”，可以继续发送。
- [ ] 图片：选图、预览、发送；只支持文本的模型不允许附图。
- [ ] 长会话（几十轮）打开和滚动不卡顿，侧边“回合导航”可跳转。
- [ ] 回退、编辑后重发、从某条分支，结果与预期一致。

## 4. 观察与对比

- [ ] 展开回复详情：用量、联网来源、校验结论正确；“调用链”加载出各阶段，跳过的阶段写明原因，标题行显示辅助调用占比。
- [ ] 极简 / 标准 / 智能各发一轮，调用链里启用和跳过的阶段与模式相符（极简只有生成；智能有路由，必要时有校验）。
- [ ] 协议报文：调用链底部点某次调用，请求页是格式化 JSON 和 URL，响应页是原始 SSE 行；报文里看不到 API Key 和请求头，图片只显示长度。设置里关闭“记录协议报文”后，新回合不再有报文。
- [ ] 重答：用户消息菜单 → 换个模型或模式重答，生成新分支并自动发送；两个回答都显示“2 答”，对比面板能看到两次回答并能跳转。
- [ ] 评价：回答菜单标“好答案 / 不好”，底部出现标记，统计页的评价数随之变化。
- [ ] 统计页：7 / 30 / 90 天切换正常，数字与实际使用大致相符。

## 5. 联网与工具（有对应能力的模型）

- [ ] 联网“自动”：时效性问题触发联网，调用链里联网规划写明查询，来源可点开。
- [ ] 联网“开启”：强制检索；“关闭”：不联网。
- [ ] 支持客户端工具的模型：子任务、web_search / web_fetch 工具轮次正常，调用链里能看到多轮生成和子任务用量。

## 6. 稳定性

- [ ] 生成中强杀应用后重开：该会话标为失败，最后一轮的调用链状态为 `process_died`，可以继续发送。
- [ ] 断网时发送：错误提示清楚，恢复网络后可以重发。
