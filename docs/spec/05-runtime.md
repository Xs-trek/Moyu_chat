# 05 运行时：写入归属、线程、截止时间、观察

## R1 写入归属 ✅（大体）⚠️（N7）

借鉴 LangGraph：每个环节只写自己负责的字段，按字段更新，不整份覆盖。

### 会话表

| 字段 | 谁写 | 怎么写 |
|---|---|---|
| 设置：模型、推理深度、联网模式、档位、预设、子任务模式 | intent：改设置 | 整行写入，前提是会话没在生成（T9） |
| 标题 | intent：改名；命名结果（在 intent 线程上应用） | 改名直接写；命名只在标题仍是原值时替换 |
| 草稿、草稿图片 | intent：存草稿、加图、移图；接收回合；发送被拒；编辑；重试 | 按字段写 |
| 状态、更新时间、预览 | 回合接收和收尾；回退 | 按字段写；收尾失败时的兜底现在是整行写（N7） |
| 路由分类 | 现状：路由阶段写，回退时清空，创建分支或重答时设置。D8 实现后不再写入（列保留不用，不改 schema） | 按字段写 |
| 压缩摘要、覆盖范围 | 压缩（回合内同步或后台）；编辑、回退、切换版本时清空 | 按字段写。后台结果写入前，核对被总结的那段历史没变（T8） |
| 索引进度 | 检索索引 | 按字段写 |

**规则**：

- 整行写入（`saveSession`）只允许在 intent 线程上、会话没在生成时进行，或者用于新建会话。
- 异步环节（准备、校验、命名、检查）一律按字段写。

### 时间线、回合记录、归档

| 对象 | 谁写 |
|---|---|
| 用户消息、正在生成的行、回合记录 | 回合接收，一个事务 |
| 正在生成的行的更新 | 回合内的流式投影 |
| 回答定稿、错误行 | 回合收尾。D4 实现后，本回合的工具调用和结果随回答一起写入 |
| 删除行、转入归档 | 回退、编辑、重试、删除会话 |
| 回合用量、调用链 | 回合收尾；回合结束后的辅助调用按回合 ID 追加（T8） |
| 评价、校验反馈 | intent，会话没在生成时 |

### 账号和模型的检查结果

- 模型列表和连接测试的结果，在数据库锁内重新核对端点和模型后才写入（A03）。

## R4 截止时间与排队 ✅

**原则**：

- 截止时间由原生决定。前端等待时间不短于原生最长耗时。
- 不允许看不见的排队：需要排队的地方必须在界面上显示；否则满了就直接拒绝。

| 操作 | 原生上限 | 前端 |
|---|---|---|
| 主调用（流式） | 连接 20 秒，两次数据之间 360 秒，总计 30 分钟 | 不等待，靠视图推送 |
| 路由 / 规划 / 命名 | 8 / 10 / 20 秒 | 不等待 |
| 压缩 | 后台 60 秒（D2）；现状为回合内 15 秒 | 不等待；下一回合必须等它时，界面显示“正在整理上下文” |
| 校验 / 修正 / 子任务 | 25 / 40 / 45 秒 | 不等待 |
| 主机联网检索 | 每个请求 25–28 秒 | 不等待 |
| Key 检查、模型列表、余额 | 30 秒 | 45 秒 |
| 连接测试 | 60 秒 | 80 秒 |
| 其他带返回数据的 intent（只读本地数据） | 立即 | 15 秒 |

**排队**：

- 路线并发上限：超过上限的回合排队，界面显示“排队中”，可以停止。
- 账号检查：同时最多 3 项，满了直接拒绝。
- intent 线程：先进先出，每个 intent 只做本地操作。

## R5 观察 ✅（大体）⚠️（N2，D6、D7 后由设计解决）

- **调用链**：
  - 每个阶段记录：状态、耗时、判断摘要；跳过的阶段记原因。
  - 原因用固定代码：档位不运行、预设不运行、用户关闭、不需要、已有产物等。
- **用量**：每次模型调用都归到发起它的阶段，并分为主调用、辅助、子任务三类。
- **要求**：
  - 每个模块都要能在调用链里看到投入（调用次数、token、耗时）和产出（判断、注入了多少内容、是否被采用）。
  - 现状：分支检索和跨会话记忆的预注入看不到（N2）。按 D6 删除分支检索、按 D7 把记忆改成工具后，它们都成为调用链里的工具调用。
- **协议报文**：脱敏后的请求和响应原文，不含请求头和 API Key，只保留最近 30 回合，可以关闭。
- **统计**：
  - 按模型 × 档位 × 预设 × 开关组合汇总。
  - 只能看相关性，不是对照实验；样本少时趋势不可靠（见[不成熟](decisions.md#不成熟的部分)）。
