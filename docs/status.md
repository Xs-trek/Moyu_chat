# 功能状态清单

后续审查以这份清单为基线：已实现的按缺陷处理，开发中的不算缺陷，待实现的是需求待办。更新于 2026-10-14（遗留项批次之后）。

## 已实现

| 范围 | 内容 | 说明 |
|---|---|---|
| 对话 | 流式回答、推理显示、编辑 / 回退 / 分支 / 换模型重答、回答对比、评价 | |
| 对话 | 失败或未完成的最后一轮可“重试”（回退后用当前设置重发） | 失败那一轮转入归档，新回合关联到它（第几次尝试、上一次结果）；统计和预算继续计入 |
| 对话 | 限流 / 过载 / 5xx 在没有输出前自动重试 ≤2 次 | `Retry-After` ≤ 60 秒 |
| 对话 | 后台完成 / 失败通知、全屏看图、跨天日期、上下文占用百分比 | |
| 对话 | 全局自定义指令 | 进入主调用的系统指令和智能校验 / 修正的证据；每轮配置里记录 |
| 对话 | Markdown（列表、代码、表格）与数学公式（本地 KaTeX） | `$…$`、`\(…\)`、`$$…$$`、`\[…\]` |
| 上下文 | 极简 / 标准 / 智能，压缩检查点，跨会话记忆检索 | 记忆按块索引、增量更新，中文按二元词检索 |
| 编排 | 辅助模块全局开关（路由、压缩、联网规划、校验修正、子任务） | 只能关掉模式本来会运行的；每轮记录，统计可按开关组合分组 |
| 账号 | 账号 → 路线 → 模型，能力逐项标来源 | `docs/provider-config.md` |
| 账号 | 检查 Key、端点模型列表、连接测试、DeepSeek 余额 | 地址改变后旧端点的证据作废 |
| 账号 | 费用估算、每日 / 每月预算（达到后每轮确认）、路线并发上限 | |
| 观察 | 调用链、协议检查器、统计（按模型 / 协议 / 深度 / 模式 / 辅助开关分组，中位数、缓存、费用）、修正前原文 | 重试、回退、删除会话移除的回合进归档（schema 2），统计默认计入 |
| 安全 | Key 只在原生安全存储，只发往确认过的域名，不跟随重定向，错误摘要抹掉 Key，搜索后端不用模型 Key | 个人自用，只防误配导致的泄漏，不做更复杂的密钥治理 |
