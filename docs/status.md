# 功能状态清单

后续审查以这份清单为基线：已实现的按缺陷处理，开发中的不算缺陷，待实现的是需求待办。更新于 2026-10-15（6Astra 审查修复与编排调整之后）。

## 已实现

| 范围 | 内容 | 说明 |
|---|---|---|
| 对话 | 流式回答、推理显示、会话内消息树：编辑、重答（可换模型或模式）、重试都产生可切换的版本（‹ 1/2 ›），“回到这里”和“回到最新”；在新会话中分支；回答对比、评价 | 不删除任何内容；切到别的版本时，那条路径之外的内容不进上下文、不被回查 |
| 对话 | 失败或未完成的最后一轮可“重试”：用当前设置在同一条提问下产生新的回答版本 | 失败的版本保留，新回合关联到它（第几次尝试、上一次结果） |
| 对话 | 限流 / 过载 / 5xx 在没有输出前自动重试 ≤2 次 | `Retry-After` ≤ 60 秒 |
| 对话 | 后台完成 / 失败通知、全屏看图、跨天日期、上下文占用百分比 | |
| 对话 | 新会话发出第一条消息后才列出（未发的草稿列为“草稿”）；自动命名（首条消息作临时标题，首轮完成后模型命名，不覆盖手动改名）；“重新命名（自动）” | 命名始终开启，按用户决定不设开关 |
| 对话 | 会话列表长按多选、批量删除（确认一次；进行中的会话跳过） | 不做分类、归档等管理功能 |
| 界面 | 应用图标“涟漪”（深水面上露出一片橙色鱼鳍），自适应图标，带 Android 13 主题图标单色层；通知栏图标同一图形 | 纯矢量，minSdk 26 不需要位图 |
| 界面 | 像素小鱼“团子鱼”：逐帧动作；趴在输入框上沿跟随回合阶段；老板键（双击标题伪装成文档）；等回答超过 10 秒可玩小游戏；轻量彩蛋（摸摸、连点、稀有锦鲤、点赞点踩、里程碑烟花、深夜哈欠、吞掉删除、空闲小动作、看你打字、长回答擦汗、摸鱼时间、急刹车） | 不做节日类彩蛋；状态（伪装、最高分、锦鲤日期）存原生设置 |
| 对话 | 全局自定义指令 | 进入主调用的系统指令和智能校验 / 修正的证据；每轮配置里记录 |
| 对话 | Markdown（列表、代码、表格）与数学公式（本地 KaTeX） | `$…$`、`\(…\)`、`$$…$$`、`\[…\]` |
| 上下文 | 极简 / 标准 / 智能；接近上限才压缩（回合结束后按实际用量在后台进行，摘要放在消息最前）；工具调用和结果作为历史保存、重放，旧结果超限时清除；跨会话记忆检索 | 记忆按块索引、增量更新，中文按二元词检索 |
| 编排 | 辅助模块全局开关（路由、压缩、原文回查、联网规划、校验修正、子任务）；跨会话检索用全局设置 | 只能关掉模式本来会运行的；路由默认关、每回合判断不存；辅助阶段累计 90 秒后跳过还没开始的修正；每轮记录，统计可按开关组合分组 |
| 编排 | 联网由回答的模型决定：有服务商联网用它，否则用 web_search / web_fetch，各档都有；“开启”时主机先搜一次；两者都没有时主机按规划检索。原文回查：历史被舍弃或压缩后，模型可用 `history_recall` 搜回本会话原话；跨会话检索：`conversation_search` | 回查每轮 ≤3 次，只搜当前会话（分支含起点快照）；按发起那一轮的上下文排除已有内容，回查结果占预算后下一轮可能再挤掉的部分不再补查 |
| 编排 | 校验后的修正版要通过复查才替换原回答，否则作为“没采用的修正版”保留对照 | |
| 账号 | 账号 → 路线 → 模型，能力逐项标来源 | `docs/provider-config.md` |
| 账号 | 检查 Key、端点模型列表、连接测试、DeepSeek 余额 | 地址改变后旧端点的证据作废；同时最多 3 项检查，满了直接拒绝不排队 |
| 账号 | 费用估算、每日 / 每月预算（达到后每轮确认）、路线并发上限 | |
| 观察 | 调用链、协议检查器、统计（按模型 / 协议 / 深度 / 模式 / 辅助开关分组，中位数、缓存、费用）、修正前原文 | 删除会话移除的回合进归档，统计默认计入（schema 3 起重试、编辑、回退不再移除回合） |
| 安全 | Key 只在原生安全存储，只发往确认过的域名，不跟随重定向，错误摘要抹掉 Key，搜索后端不用模型 Key | 个人自用，只防误配导致的泄漏，不做更复杂的密钥治理 |
